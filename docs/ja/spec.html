1動作環境

項目内容
WindowsWindows 10 / 11（x64）。WebView2 ランタイムが要ります（Windows 11 と更新済みの 10 には既に入っています）
macOSmacOS 11 以降（Apple Silicon）。Intel 版はありません
Linuxビルドは配っていません（Tauri v2 なので技術的には対象です）
追加の部品HEIC / HEVC の画素は OS の拡張機能を使います。Windows では「HEIF 画像拡張機能」（無償）と「HEVC ビデオ拡張機能」（有償）
言語日本語 / 英語。OS の言語に従い、設定で上書きできます

2できること

USB / SD カードからの取り込み

撮影日ごとのフォルダに仕分け。9 つの雛形か、自分で書いた並びで

フォルダをそのまま登録

写真を独自の保管庫へ移し替えません。元の場所のまま並べます

撮影日ごとの一覧とカレンダー

年のスクラバーで数万枚を一息に移動できます

検索・絞り込み

ファイル名・フォルダ・カメラ・撮影年月日・★・⚑。すべて AND です

ビューアと選別

⚑ で抜き、✕ でボツ、★ でお気に入り。撮影情報（絞り・SS・ISO・GPS）も出ます

まとめて操作

選んだぶんを ★ 付け／フォルダへコピー・移動／ごみ箱へ

スライドショーと動画再生

再生できないコンテナは、既定のプレイヤーへ渡します

自動再生への登録（Windows）

カードを挿したときの候補に出ます。勝手には起動しません

3できないこと

意図して入れていないものと、まだ手が回っていないものを分けて書きます。

できないこと理由・現状
RAW 現像入れていません。カメラが埋め込んだ表示用 JPEG を使います
写真の編集・書き出し回転も切り抜きもありません。見るための道具です
AI による選別・顔認識入れていません。選ぶのは撮った本人です
タグ・キーワード付けありません。★ と ⚑ の 2 つだけです
並び順の変更撮影日の新しい順のみ。指定する手段がありません
取り込みの中断始めたら最後まで走ります
動画のサムネイル（macOS / Linux）Windows のみ対応。その他は未対応（未実装）です
.m2ts / .avi のアプリ内再生WebView がそのコンテナを扱えません。一覧には出ます
索引の作り直し（画面から）設定フォルダの pictkura.db を消すと作り直します
右から左に書く言語の配置未対応です

4対応しているファイル形式

一覧・拡大とも可 制限あり — 非対応

4.1  写真

拡張子一覧拡大備考
jpg  jpeg縮小しながら復号するので、大きな写真でも重くなりません
png  webp
avifデコーダ（rav1d）を同梱。OS の拡張機能は要りません
heic  heif  hifiPhone の既定。画素の復号は OS に任せます
bmp  gif  tif  tifftiff はブラウザが描けないので JPEG に包み直します
svg原本から描くので、どこまで拡大しても崩れません

4.2  RAW  — 現像はしません

拡張子一覧拡大備考
cr2 cr3 nef nrw arw raf orf rw2 pef srw dng rwl 3fr x3f kdcカメラが埋め込んだ表示用 JPEG を、ほぼ元の大きさで取り出します。Apple ProRAW（DNG）を含みます
crw srf sr2 mrw erf dcr iiq mos raw試したファイルでは 160×120〜640×480 の小さなプレビューしか無く、全画面では甘くなります
fffHasselblad。試した H5D-40 のファイルはプレビューを持たず、枠だけが出ます
ptx??Pentax。拡張子は見ますが、実ファイルを入手できず未確認です
Blackmagic CinemaDNGプレビューを持ちません

2026-08-20 に、16 メーカー 28 個の実ファイル（photographyblog.com のサンプルと raw.pixls.us の CC0 一覧）で確認しました：表示用 JPEG が取り出せること、縦位置が正しく立つこと、撮影日とカメラ名が読めること。

4.3  動画

拡張子一覧アプリ内再生備考
mp4  m4v  mov  webmコーデックは OS のものを使います（HEVC は上記の拡張機能が要ります）
avi mts m2ts mkv 3gp wmv mpg mpeg—サムネイル・長さ・日付は出ます。再生は既定のプレイヤーが開きます

動画のサムネイルは OS から借ります（現在 Windows のみ）。長さ・寸法・撮影日時はコンテナのヘッダから読み、1 画素も復号しません。

5通信とプライバシー

項目内容
自分から出す通信起動時の更新確認だけ（自動の確認は 1 日 1 回まで）。送るのは「pictkura のバージョン X が尋ねている」という情報のみです
送らないもの写真・ファイル名・フォルダの場所・利用状況。解析や計測の仕組みは入っていません
通信を止める設定 →「pictkura について」→「起動時に更新を確認する」を切ると、通信は 1 本も出ません
クラウドのファイル実体が無いファイルを勝手に取りに行きません。実際に見たときだけ取得します
削除必ずごみ箱を通ります。直接消すことはありません

プライバシーポリシーにも同じ内容を、文書の形で置いています。

6データの置き場所

中身場所
設定（Windows）%APPDATA%\dev.harusame.pictkura\pictkura.toml
設定（macOS）~/Library/Application Support/dev.harusame.pictkura/
索引pictkura.db（同じフォルダ）
サムネイルthumbs\（同じフォルダ）
写真そのもの触りません。登録したフォルダにあるままです

設定ファイルは手で編集できます。画面に出していない細かい設定（走査から除くフォルダのパターン、写真と一緒に運ぶファイルの拡張子など）は、マニュアルに書いてあります。
