pictkura（以下「本アプリ」）は、個人が趣味として制作し、MIT ライセンスに基づいて無償で公開しているソフトウェアです。利用を開始した時点で、以下に同意したものとみなします。

本アプリは MIT ライセンスで提供されます。著作権表示とライセンス条文を残すかぎり、使用・複製・改変・再配布・販売のいずれも自由に行えます。原文が正であり、このページはその案内にすぎません。

本アプリの使用または使用不能から生じたいかなる損害（写真・動画・その他データの消失または破損、機会の逸失を含みます）についても、制作者は責任を負いません。

大切な写真は、必ず別の場所にも控えを取ってから使ってください。 本アプリは削除を必ずごみ箱経由で行い、取り込みではコピー後にファイルの大きさを検証しますが、それでも唯一の保管手段にはしないでください。

3写真とデータの取り扱い

本アプリは写真を独自の保管庫へ取り込み直さず、利用者が指定したフォルダにあるファイルをそのまま扱います。削除の操作は必ず OS のごみ箱を経由し、本アプリがファイルを直接消去することはありません。

取得・送信する情報についてはプライバシーポリシーに定めます。写真そのものが外部へ送信されることはありません。

不具合の報告・要望は GitHub の Issues でお受けしますが、回答・修正・対応の期限をお約束するものではありません。個別のサポート窓口や電話での対応はありません。

脆弱性を見つけた場合も、同じ窓口へご連絡ください。内容によっては、公開の場での詳細な記載を控えていただくようお願いすることがあります。
