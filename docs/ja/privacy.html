プライバシーポリシー

pictkura（以下「本アプリ」）と、このウェブサイトにおける個人情報の扱いについて定めます。本アプリは、写真・ファイル名・フォルダの場所を含む、利用者のデータを一切送信しません。

制定  2026-08-22 最終改定  2026-08-22

1本アプリが取得する情報

本アプリは、利用者の個人情報を取得しません。写真、その内容、ファイル名、フォルダの構成、操作の記録は、いずれも利用者の PC の中だけで扱われ、外部に送信されることはありません。利用状況の解析（アナリティクス）やクラッシュ情報の自動送信の仕組みも組み込んでいません。

2本アプリが行う唯一の通信

本アプリは、起動して数秒後に、新しいバージョンが公開されているかを確認します。この自動の確認は 1 日 1 回までです（設定画面の「更新を確認」ボタンは、押したときにその場で確認します）。この確認では「pictkura のバージョン X が問い合わせている」という情報のみが送信され、写真・ファイル名・フォルダの場所・利用者を識別する番号は送信されません。

確認先は GitHub のリリース情報です。通信の性質上、接続元の IP アドレスは接続先（GitHub 社）に伝わります。設定 →「pictkura について」→「起動時に更新を確認する」を無効にすると、本アプリは一切ネットワークに接続しません（無効にしたあとも、隣の「更新を確認」ボタンを押したときだけは確認します）。

3クラウド上のファイルの取り扱い

OneDrive などで「オンラインのみ」となっているファイルについて、本アプリが自動的に実体をダウンロードすることはありません。利用者が実際にその写真を表示したとき（一覧で画面に入ったとき、またはビューアで開いたとき）にのみ、OS を通じて取得されます。

4このウェブサイトについて

本サイトは GitHub Pages（GitHub 社）でホストしています。同社は、サーバの運用およびセキュリティの目的で、アクセス元の IP アドレスを含む接続記録を取得する場合があります。詳細は同社のプライバシーに関する文書をご確認ください。

本サイトは、書体の表示に Google Fonts（Google LLC）を利用します。これにより、閲覧者の IP アドレスおよびブラウザの情報が同社に送信されます。

本サイトは、Cookie を使用せず、アクセス解析ツールを設置していません。広告も掲載しません。なお、アプリに同梱している取扱説明書（アプリの設定から開くもの）は、外部への通信を一切行いません。

5お問い合わせで受け取る情報

不具合の報告や要望は GitHub の Issues でお受けします。GitHub 上のやり取りは公開され、投稿者のアカウント名が表示されます。連絡先などの個人情報を書き込まないようご注意ください。

6本ポリシーの改定

内容を変更した場合は、このページに改定日を記載して掲示します。重要な変更については、リリースノートにも記載します。
