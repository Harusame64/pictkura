pictkura 1.0.0 is also on the Microsoft Store. This release adds a right-click menu with file
info, rotation, copy and print, smoother ways around the grid and the viewer, and more careful
deleting, moving and counting.

## Highlights

### Microsoft Store

pictkura is on the Microsoft Store: https://apps.microsoft.com/detail/9N5H2QBMK9NB.

- **The Store installs and updates it.**
- **It shares your library.** If you have used another Windows build of pictkura with the same Windows
  account, the Store version uses the same library and settings.
- **Moving from the installer version? Uninstall it first.** The Store version cannot remove the
  AutoPlay entry the installer version left, so two entries with the same name would appear.

### Right-click menu

- **Info:** name, folder, size, dates, pixel dimensions and type for each file of the tile. A
  RAW+JPEG pair shows both files. The viewer's info panel (I) shows the same, and a short line
  under the selection bar gives the name, date and size.
- **Copy image to clipboard.**
- **Rotate right / Rotate left (JPEG): lossless.** Only the orientation tag is rewritten; the
  picture data is not re-encoded. **Restore original orientation** undoes it. Re-importing a card
  does not bring a rotated photo in again.
- **Print…: one photo per page**, fitted, cropped or stretched. Shooting data (EXIF, GPS) is not
  passed to the printer or the PDF.
- **Show more options (Windows)** opens File Explorer's own menu for the photo: Send to,
  Open with, Properties and so on.

**To print several photos**, use **Print…** on the selection bar: 1, 2, 4, 6 or 9 per page, with
the file name and date taken under each if you want.

## Grid and viewer

- **Zoom from the tile.** Opening a photo zooms it out of its tile, and closing returns it there.
  Nothing moves if your system is set to reduce motion.
- **Spread a stack in place.** Click the RAW+JPEG or Burst badge on a stacked tile to spread its
  frames where they sit. **Fold** puts them back. Clicking elsewhere on the tile still opens the
  viewer.
- **The info panel makes room for itself** instead of covering the photo and Next.
- **Video volume and mute are remembered.** A silent video shows a speaker mark; press it to turn
  the sound on.
- **Background work, quietly.** A line in the header shows work such as a folder being scanned or
  new photos still being read. A normal launch shows nothing, and the startup speed notice is gone.

## Import, AutoPlay and Outgoing

- **AutoPlay now belongs to the installers (Windows).** The installers add "pictkura で写真を取り込む"
  to the AutoPlay choices ("Import photos with pictkura" in the English MSI), and uninstalling
  removes it. The app itself no longer writes to the registry, and the Settings checkbox is gone.
  The portable build does not offer the entry. Settings has a button that opens Windows' AutoPlay
  settings.
  - The entry that older versions registered from the app is cleaned up when you install. If you
    had chosen pictkura as the AutoPlay default, that choice carries over.
- **The MSI installs to Program Files** even if the -setup.exe version was on the PC before. It used
  to pick up the folder the -setup.exe version had left in your user profile. A folder you choose
  yourself is kept.
- **A single camera card is preselected.** The import screen also makes cards and removable drives
  stand out, and starting an import scrolls to its progress.
- **Settings tells you when an import arrives** while it is open, with **Close and import**.
- **Outgoing folders are easier to reach.** Settings and the Outgoing view have **Open folder** and
  **Copy path** for each Outgoing folder, including those on earlier drives. The Outgoing view says
  which folder to choose in your photo service.

## Safer file operations

- **An unplugged card is no longer "deleted".** Deleting photos on a card or drive that was just
  unplugged used to count them as deleted and drop their ★/⚑ while the files were still on the
  card. It now says the drive cannot be reached.
- **One at a time.** Only one delete, move or copy runs at a time, and closing the window waits for
  it to finish.
- **Counts are of files everywhere.** The selection bar, confirmations and results agree, for
  RAW+JPEG pairs and bursts too.
- Photos that were already gone are reported as "no longer in the library" in delete, move and
  copy results.
- The progress line clears when a delete or export fails.
- Files deleted outside pictkura leave the selection. The viewer stays on a photo whose date
  changed when it was overwritten.
- A folder path that is not a full path (such as `J:photos`) is refused.
- Copying an image holds the Windows clipboard only briefly.

## Accessibility and automation

Buttons that show only a symbol have names. Toggles report their state, dialogs and menus have
roles, and the background behind a dialog can no longer be reached. Clickable items work from the
keyboard. Main controls have stable automation IDs that do not change with the language.

## Upgrading from 0.3.0

- **Windows**: run the new installer over the old one. To move to the Store version, uninstall
  the installer version first (see above).
- **macOS**: unzip the new `pictkura.app` and replace the old one. The Gatekeeper steps in the
  [README](https://github.com/Harusame64/pictkura#readme) are needed again.
- Your library, settings, favourites (★) and picks (⚑) are kept.

## Known gaps

The list of what pictkura does not do yet is in the [README](https://github.com/Harusame64/pictkura#readme).

# 日本語

pictkura 1.0.0 から、Microsoft Store でも配ります。右クリックのメニューに、ファイルの情報・回転・
コピー・印刷が加わりました。一覧とビューアを使いやすくし、ゴミ箱・移動・枚数の数え方もより慎重に
しました。

## ハイライト

### Microsoft Store 版

pictkura を Microsoft Store からインストールできます：https://apps.microsoft.com/detail/9N5H2QBMK9NB。

- **インストールも更新も Store が行います。**
- **ライブラリはそのまま使えます。** 同じ Windows のアカウントでほかの Windows 版の
  pictkura を使っていたなら、同じライブラリと設定を使います。
- **インストーラー版から移るときは、先にアンインストールしてください。** インストーラー版が登録した
  自動再生の候補を Store 版からは消せないため、同じ名前の候補が2つ並びます。

### 右クリックのメニュー

- **情報**：タイルに含まれるファイルごとに、名前・フォルダ・サイズ・日付・縦横の画素数・種類を
  出します。RAW と JPEG の組なら両方です。ビューアの情報パネル（I）にも同じ内容が出ます。
  選択バーの下には、名前・撮影日・サイズの短い行が出ます。
- **画像をクリップボードへコピー**
- **右に回転・左に回転（JPEG）：画質は落ちません。** 書き換えるのは向きの情報だけで、画素は
  作り直しません。**向きを元に戻す**で取り消せます。回転した写真は、カードを取り込み直しても
  重複して入りません。
- **印刷…：1ページに1枚。** 用紙に合わせる・切り取って余白をなくす・引き伸ばすの3通りから選べます。
  撮影情報（EXIF・GPS）は、プリンターにも PDF にも渡りません。
- **その他のオプションを表示（Windows）**：エクスプローラーのメニュー（送る・プログラムから開く・
  プロパティなど）を開きます。

**何枚もまとめて刷るとき**は、選択バーの「印刷…」で、1ページに 1・2・4・6・9 枚を選べます。
各写真の下に、ファイル名と撮影日を入れることもできます。

## 一覧とビューア

- **タイルから拡大して開く**：写真を開くとタイルから拡大し、閉じるとタイルへ戻ります。OS で
  「動きを減らす」にしていれば動きません。
- **重なりをその場で広げる**：重なったタイルの「RAW+JPEG」「連写」の印を押すと、その場でコマが
  広がります。「たたむ」で戻ります。印以外の所を押せば、これまでどおりビューアが開きます。
- **情報パネルが写真に重ならない**：ビューアの情報パネルは、写真と「次へ」に重ならず、横に並びます。
- **動画の音量を覚える**：音量と消音を覚えます。音の出ない動画にはスピーカーの印が付き、押すと
  音が出ます。
- **裏の作業を控えめに出す**：フォルダを調べている・新しい写真を読み込んでいる、などをヘッダーに
  1行で出します。ふつうの起動では何も出ません。起動の速さの知らせは無くなりました。

## 取り込み・自動再生・送り出し

- **自動再生はインストーラーが登録します（Windows）**：候補「pictkura で写真を取り込む」は
  インストーラーが登録し、アンインストールで消えます（英語版の MSI では「Import photos with
  pictkura」）。アプリ自身はレジストリに書かず、設定のチェックボックスは無くなりました。持ち歩き版は
  候補に出しません。設定には、Windows の自動再生の設定を開くボタンがあります。
  - 前の版がアプリから登録した候補は、インストールしたときに片付きます。自動再生の既定に pictkura を
    選んでいた場合、その選択は引き継がれます。
- **MSI は Program Files にインストールされます**：前にインストーラー版（-setup.exe）をインストールしていた PC でも
  同じです。これまでは、インストーラー版がユーザーのフォルダに残した場所を拾っていました。自分で
  選んだ場所はそのまま使います。
- **カードが1枚なら選んだ状態で開く**：取り込みの画面は、カメラのカードが1枚だけならそれを選んだ
  状態で開きます。カードやリムーバブルドライブは目立たせ、取り込みを始めると進み具合の所まで
  表示が移ります。
- **設定を開いていても取り込みに気づける**：設定を開いている間に取り込みが届くと、設定の中で
  知らせます。「閉じて取り込む」で開きます。
- **送り出しフォルダを開きやすく**：設定と「送り出し」の画面で、それぞれの送り出しフォルダを
  「フォルダを開く」「パスをコピー」できます。前に使ったドライブのフォルダもです。「送り出し」の
  画面では、写真サービスにどのフォルダを登録すればよいかを案内します。

## ファイルの扱いをより慎重に

- **抜いたカードの写真を「消した」と数えない**：抜いたばかりのカードやドライブの写真をゴミ箱へ
  入れると、これまではファイルがカードに残っているのに「消した」と数え、★/⚑ も消えていました。
  いまは「ドライブまたはフォルダに届きません」と伝えます。
- **1つずつ動く**：ゴミ箱・移動・コピーは1つずつ動きます。動いている間に窓を閉じると、終わるのを
  待ってから閉じます。
- **枚数はどこでもファイルの数**：RAW と JPEG の組や連写でも、選択バー・確認・結果の数が合います。
- ゴミ箱・移動・コピーの結果で、すでに無くなっていた写真は「ライブラリから無くなっていた」と
  数えます。
- ゴミ箱や書き出しに失敗したとき、進み具合の行が残らなくなりました。
- pictkura の外で消したファイルは、選択から外れます。開いている写真が上書きされて撮影日が
  変わっても、ビューアはその写真に留まります。
- 完全なパスでないフォルダ（`J:photos` など）は受け付けません。
- Windows で画像をコピーするとき、クリップボードを掴む時間を短くしました。

## 読み上げと自動操作

記号だけのボタンに名前を付けました。切り替えのボタンは状態を伝え、ダイアログとメニューには
役割が付きました。ダイアログの後ろには届かなくしました。押せる項目はキーボードでも押せます。
主な操作には、言語で変わらない自動操作用の ID を付けました。
