pictkura 0.3.0 adds Outgoing: a folder where pictkura lines up only the photos you want a
photo service to upload. It also says why the grid is empty when a
filter leaves nothing, and makes the command palette run what you type.

## What's new

### Outgoing

Some photo services upload everything in a folder you add, RAW files and videos included.
pictkura now keeps an **Outgoing** folder with only what should go up, and you add that folder to
the service instead of your library. pictkura does not talk to the service. How it works, with
diagrams: [Outgoing](https://harusame64.github.io/pictkura/en/outgoing.html).

- **Turn it on** in Settings → **Outgoing**. It is off by default.
- **Each import lines up the copied photos there**, in the same folder layout as your library.
  - Photos are placed as hard links, so they take no extra disk space.
  - For a RAW+JPEG pair, only the JPEG. For RAW-only shots, choose **Leave out** or
    **Place the embedded JPEG** (the camera's preview, with the capture date).
  - A burst goes in as one frame. A frame you mark ⚑ later is added too.
  - Videos follow **Place videos too**. Photos inside OneDrive are left out unless you turn
    them on.
- **Send earlier photos** from the selection bar or the right-click menu (**Add to Outgoing**),
  or a whole month or year from the calendar.
- **See what is there** with **Outgoing** under Places on the left, and **Remove from Outgoing**
  there. Removing never touches your originals or what is already uploaded.
- **Deleting a photo in pictkura takes it out of Outgoing too.**
- One Outgoing folder is made per drive (hard links cannot cross drives). Settings lists them
  all. exFAT/FAT drives cannot hold one.
- **If you use Google Photos:** add the Outgoing folder with "Back up a folder" on
  photos.google.com. The upload runs while that page is open in your browser.

Google Photos is a trademark of Google LLC.

### Smaller things

- **When a filter leaves nothing, the grid says which conditions did it**, for example "No
  photos match these filters: ★ Favorites, Videos", with **Clear search** and **Show all
  photos** buttons. Before, the grid was blank.
- **In the command palette (Ctrl+K / ⌘K), an action whose name starts with what you type comes
  first**, so Enter runs it. Actions also match their English name in every language, so
  `all` finds **Show all photos** without switching your input method.
- **Show all photos in the palette also clears the kind filter** (Photos / RAW / Videos).

## Downloads

| You want | File |
|---|---|
| Windows 10/11, the usual case | `pictkura_0.3.0_x64-setup.exe` — no administrator rights |
| Windows, machine-wide install (for administrators) | `pictkura_0.3.0_x64_ja-JP.msi` / `_en-US.msi` |
| Windows, no installer | `pictkura_0.3.0_x64-portable.zip` |
| macOS 11+ (Apple Silicon) | `pictkura_0.3.0_arm64.zip` |

Neither build is code-signed, so Windows shows SmartScreen and macOS shows Gatekeeper on
first launch. The [README](https://github.com/Harusame64/pictkura#readme) walks through
both, including the extra steps macOS 15 needs.

## Upgrading from 0.2.9

- **Windows**: run the new installer over the old one.
- **macOS**: unzip the new `pictkura.app` and replace the old one. The Gatekeeper steps in
  the [README](https://github.com/Harusame64/pictkura#readme) are needed again.
- Your library, settings, favourites and picks are kept. Outgoing stays off until you turn it
  on.

## Known gaps

The list of what pictkura does not do yet is in the [README](https://github.com/Harusame64/pictkura#readme).

# 日本語

pictkura 0.3.0 では「送り出し」を足しました。写真サービスへ上げたいものだけを、pictkura が
フォルダに並べておく機能です。あわせて、絞り込んで0件の
ときに理由を言うようにし、コマンドパレットで打った操作がそのまま走るようにしました。

## 新しくなったところ

### 送り出し

写真サービスの中には、登録したフォルダの中身を、RAW や動画も含めて丸ごとアップロードするものが
あります。pictkura が上げてよいものだけを**送り出し**フォルダに並べ、写真サービスにはライブラリ
ではなくそのフォルダを登録します。pictkura は写真サービスと通信しません。図を交えたしくみの説明は
[「送り出し」のページ](https://harusame64.github.io/pictkura/ja/outgoing.html)にあります。

- **設定 →「送り出し」で入れます。** 既定は切です。
- **取り込むたびに、コピーした写真がそこに並びます。** フォルダの形はライブラリと同じです。
  - ハードリンクで置くので、ディスクは余分に使いません。
  - RAW と JPEG の組は JPEG だけ。RAW だけのカットは「置かない」か「埋め込み JPEG を置く」
    （カメラが RAW に入れている表示用の絵に、撮影日時を付けたもの）を選べます。
  - 連写は1枚だけ置きます。あとで ⚑ を付けたコマも足します。
  - 動画は「動画も置く」に従います。OneDrive の中の写真は、設定で入れたときだけ置きます。
- **前に取り込んだ写真も送れます。** 選択バーと右クリックの「送り出しへ」、カレンダーの月・年の
  まとめ送りです。
- **左の「場所」の「送り出し」で、置いたものを見られます。** そこで「送り出しから外す」が
  できます。手元の原本にも、アップロード済みの写真にも触りません。
- **pictkura で写真をゴミ箱へ入れると、送り出しからも外します。**
- 送り出しフォルダはドライブごとに1つ作ります（ハードリンクはドライブをまたげないため）。
  設定にすべて並びます。exFAT・FAT のドライブには作れません。
- **Google フォトを使う場合：**送り出しフォルダを photos.google.com の「フォルダをバックアップ」に
  登録します。アップロードは、ブラウザでそのページを開いているときだけ進みます。

Google フォトは Google LLC の商標です。

### 細かいところ

- **絞り込んで0件のとき、どの条件で0件になったかを言います。** 例「この絞り込みに該当する
  写真はありません：★ お気に入り、動画」。「検索を消す」「すべての画像を表示」のボタンも
  出ます。これまでは一覧が真っ白でした。
- **コマンドパレット（Ctrl+K / ⌘K）で、打った語で名前が始まる操作が先頭に来ます。** Enter で
  その操作が走ります。どの言語でも英語の名前で当たるので、`all` と打てば入力方法を切り替えずに
  「すべての画像を表示」が出ます。
- **パレットの「すべての画像を表示」で、種類（画像・RAW・動画）の絞り込みも外れます。**
