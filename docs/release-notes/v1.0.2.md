pictkura 1.0.2 is available in 14 languages, adding French, Italian, Russian, Portuguese (Brazil), Korean, Arabic and Hebrew. Arabic and Hebrew lay out the whole window right to left.

## New languages

- **Languages:** Added French, Italian, Russian, Portuguese (Brazil, also used in Portugal), Korean, Arabic and Hebrew. pictkura follows your OS language, or choose one in ⚙ (Settings) → **Language**.
- **Right to left:** In Arabic and Hebrew the whole window is mirrored: the sidebar, the viewer, menus and the confirmation dialogs on Windows. Arrow keys follow the reading direction (← shows the next photo).
- **Keyboard:** Shortcuts such as P, X and Ctrl+K also work on keyboard layouts that don't type Latin letters (Russian, Korean, Arabic, Hebrew and others).
- **Microsoft Store:** The Store version now lists all 14 languages as supported.

## Changes

- **Viewer:** The close button is now a ← in the top-left corner, away from the ✕ that marks a photo as rejected.
- **Windows:** On Japanese Windows, paths in the import window, the Outgoing guide and the missing-original notice now show `\` instead of `¥`.
- **Sidebar:** The "N more" / "Show less" link next to "Cameras & media" no longer breaks the heading onto two lines.

## Downloads

| You want | File |
|---|---|
| Windows 10/11, installed and updated by the Store | Microsoft Store: https://apps.microsoft.com/detail/9N5H2QBMK9NB |
| Windows 10/11, the usual case | `pictkura_1.0.2_x64-setup.exe` — no administrator rights |

The GitHub builds are not code-signed, so Windows displays a SmartScreen warning and macOS displays a Gatekeeper warning on first launch. See the [README](https://github.com/Harusame64/pictkura#readme) for instructions.

## Upgrading from 1.0.1

- **Windows:** Run the new installer to update your existing installation. The Store version updates automatically.
- **macOS:** Extract the new `pictkura.app` from the ZIP and replace the existing app. Repeat the Gatekeeper steps in the [README](https://github.com/Harusame64/pictkura#readme).
- Your library, settings, favourites (★), and picks (⚑) are preserved.

# 日本語

pictkura 1.0.2 では、表示できる言語を 14 にしました。フランス語・イタリア語・ロシア語・ポルトガル語（ブラジル）・韓国語・アラビア語・ヘブライ語を追加しています。アラビア語とヘブライ語では、画面全体を右から左に組みます。

## 言語の追加

- **言語：** フランス語、イタリア語、ロシア語、ポルトガル語（ブラジル。ポルトガルでもこちらを使います）、韓国語、アラビア語、ヘブライ語を追加しました。OS の言語に合わせて表示されます。⚙（設定）→ **言語** で選ぶこともできます。
- **右から左：** アラビア語とヘブライ語では、サイドバー、ビューア、メニュー、Windows の確認ダイアログまで、画面全体が左右反転します。矢印キーも読む向きに合わせて動きます（← で次の写真）。
- **キーボード：** ロシア語・韓国語・アラビア語・ヘブライ語など、ラテン文字を打たない配列でも P・X・Ctrl+K などのショートカットが効きます。
- **Microsoft Store：** Store 版の対応言語に 14 言語が表示されるようになりました。

## 変更点

- **ビューア：** 閉じるボタンを左上の ← にして、写真をボツにする ✕ から離しました。
- **Windows：** 日本語の Windows で、取り込み画面・送り出しの案内・元のファイルが見つからないときの表示にあるパスの `\` が、`¥` と表示されていたのを直しました。
- **サイドバー：** 「カメラとメディア」の横の「他 N 台」「閉じる」で、見出しが2行に折れなくなりました。
