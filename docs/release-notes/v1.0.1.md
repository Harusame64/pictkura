pictkura 1.0.1 fixes issues with missing WebView2 runtime handling on Windows, folder visibility during import, and dialog languages on macOS.

## Fixes

- **Windows:** Added a message when the Microsoft Edge WebView2 runtime is missing. The message appears in your OS language and offers to open Microsoft's download page before pictkura exits. Previously, pictkura remained running in the background without displaying a window or message.
- **Import:** The folder tree now expands to the folder being imported (for example, `DCIM` on a memory card), keeping the selected folder visible.
- **macOS:** Save, Open, and print panels, along with confirmation dialog buttons, now use the language chosen in Settings. Language changes take effect the next time you start pictkura.

## Downloads

| You want | File |
|---|---|
| Windows 10/11, installed and updated by the Store | Microsoft Store: https://apps.microsoft.com/detail/9N5H2QBMK9NB |
| Windows 10/11, the usual case | `pictkura_1.0.1_x64-setup.exe` — no administrator rights |
| Windows, machine-wide install (for administrators) | `pictkura_1.0.1_x64_ja-JP.msi` / `_en-US.msi` |
| Windows, no installer | `pictkura_1.0.1_x64-portable.zip` |
| macOS 11+ (Apple Silicon) | `pictkura_1.0.1_arm64.zip` |

The GitHub builds are not code-signed, so Windows displays a SmartScreen warning and macOS displays a Gatekeeper warning on first launch. See the [README](https://github.com/Harusame64/pictkura#readme) for instructions.

## Upgrading from 1.0.0

- **Windows:** Run the new installer to update your existing installation. The Store version updates automatically.
- **macOS:** Extract the new `pictkura.app` from the ZIP and replace the existing app. Repeat the Gatekeeper steps in the [README](https://github.com/Harusame64/pictkura#readme).
- Your library, settings, favourites (★), and picks (⚑) are preserved.

# 日本語

pictkura 1.0.1 では、Windows で WebView2 ランタイムがない場合の案内、取り込み時のフォルダ一覧、macOS のダイアログの表示言語を修正しました。

## 修正点

- **Windows：** Microsoft Edge WebView2 ランタイムがインストールされていない場合に、OS の言語で案内を表示するようにしました。Microsoft の入手ページを開くかどうかを確認してから終了します。これまでは何も表示されず、ウィンドウがないままバックグラウンドで動作し続けていました。
- **取り込み：** 選択中のフォルダが見えるよう、取り込み元のフォルダ（メモリーカードの `DCIM` など）までフォルダ一覧を展開するようにしました。
- **macOS：** 保存・開く・印刷のパネルと確認ダイアログのボタンに、設定で選んだ言語が反映されるようにしました。言語の変更は、次回の pictkura 起動時に反映されます。

- **macOS：** ZIP を展開し、既存の `pictkura.app` を新しいものに置き換えてください。[README](https://github.com/Harusame64/pictkura/blob/main/README.ja.md) に記載の Gatekeeper の手順を再度行う必要があります。
