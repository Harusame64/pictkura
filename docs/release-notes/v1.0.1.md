pictkura 1.0.1 fixes what happens on Windows when the WebView2 runtime is missing, and shows
macOS dialogs in the language chosen in Settings.

## Fixes

- **Windows: if the Microsoft Edge WebView2 runtime is missing, pictkura now says so.** A message
  in your OS language offers to open Microsoft's download page, and pictkura quits. Before, it
  showed nothing and stayed running in the background with no window.
- **Import: the folder tree opens down to the folder being imported** (for example `DCIM` on a
  memory card), so the selected folder is visible.
- **macOS: dialogs and panels follow the language chosen in Settings** — Save and Open panels,
  the print panel, and the buttons of confirmation dialogs. The change applies the next time you
  start pictkura.

## Downloads

| You want | File |
|---|---|
| Windows 10/11, installed and updated by the Store | Microsoft Store: https://apps.microsoft.com/detail/9N5H2QBMK9NB |
| Windows 10/11, the usual case | `pictkura_1.0.1_x64-setup.exe` — no administrator rights |
| Windows, machine-wide install (for administrators) | `pictkura_1.0.1_x64_ja-JP.msi` / `_en-US.msi` |
| Windows, no installer | `pictkura_1.0.1_x64-portable.zip` |
| macOS 11+ (Apple Silicon) | `pictkura_1.0.1_arm64.zip` |

The GitHub builds are not code-signed, so Windows shows SmartScreen and macOS shows Gatekeeper
on first launch. The [README](https://github.com/Harusame64/pictkura#readme) walks through both.

## Upgrading from 1.0.0

- **Windows**: run the new installer over the old one. The Store version updates itself.
- **macOS**: unzip the new `pictkura.app` and replace the old one. The Gatekeeper steps in the
  [README](https://github.com/Harusame64/pictkura#readme) are needed again.
- Your library, settings, favourites (★) and picks (⚑) are kept.

# 日本語

pictkura 1.0.1 では、Windows で WebView2 ランタイムがインストールされていない場合の動作を直しました。
また、macOS のダイアログを、設定で選んだ言語で表示するようにしました。

## 直したこと

- **Windows：Microsoft Edge WebView2 ランタイムがインストールされていない場合に、その旨を表示するようになりました。**
  OS の言語で案内を表示し、Microsoft の入手ページを開くかどうかを確認してから終了します。
  これまでは何も表示されず、ウィンドウの無いままバックグラウンドで動き続けていました。
- **取り込み：取り込み元のフォルダ（メモリーカードの `DCIM` など）まで、フォルダ一覧を展開して表示するようになりました。**
  選択中のフォルダが見えます。
- **macOS：ダイアログやパネルを、設定で選んだ言語で表示するようになりました。**
  対象は、保存・開く・印刷のパネルと、確認ダイアログのボタンです。
  言語の変更は、次に pictkura を起動したときに反映されます。

## 1.0.0 からの更新

- **Windows**：新しいインストーラーを、そのまま上書きで実行します。Store 版は Store が更新します。
- **macOS**：ZIP を展開し、置いてある `pictkura.app` を新しいものに置き換えます。
  [README](https://github.com/Harusame64/pictkura/blob/main/README.ja.md) の Gatekeeper の
